React 360 examples

Four demos of React 360 running on WebXR with React 16.8 hooks. Each one works with a mouse on desktop, on a WebXR headset, or in a VR emulator right in this browser.

Solar system

The Sun and eight planets orbit around you. Point at a planet to highlight it, and click to read its real facts.

three.js custom views · pointing at 3D · hooks
Open Try VR in the emulator

Controller sandbox

Pull the trigger to launch glowing shapes that float, drift and bounce around the room.

WebXR controllers · per-frame physics · native modules
Open Try VR in the emulator

Sound visualizer

Music generated live in your browser plays from a glowing orb, while a ring of columns pulses to it.

Web Audio · spatial sound · three.js effects
Open Try VR in the emulator

Code city

React 360's own source code as a city around you: every building is a file, and its height is the file's length.

React layout of 3D shapes · hover · useMemo
Open Try VR in the emulator

VR needs a browser with WebXR, such as the Meta Quest browser, and a secure page: https:// or localhost. The emulator links load Meta's WebXR emulator as a virtual Quest 3.
